# Data Analytics Lab

Laboratorio personale dedicato allo studio e alla pratica di SQL, Python e Data Analysis.

## Obiettivi

- Consolidare SQL Server e T-SQL
- Imparare a costruire analisi complete partendo da un requisito di business
- Integrare SQL e Python utilizzando SQLAlchemy e Pandas
- Acquisire dimestichezza con Git, VS Code e Docker
- Costruire un portfolio di query e analisi documentate

## Stack

- Python 3.13
- SQL Server 2022 (Docker)
- SQLAlchemy
- PyODBC
- Pandas
- VS Code
- Docker Compose

## Metodo di lavoro

Ogni esercizio nasce da una richiesta di business.

Per ogni esercizio vengono documentati:

- obiettivo;
- ragionamento;
- query SQL;
- eventuali considerazioni sul grain, sulle join e sulle scelte progettuali.

L'obiettivo non è soltanto scrivere query corrette, ma imparare a progettare analisi dati come in un contesto lavorativo reale.
